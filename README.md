# موقع طلبات المستقبل التجارية — نسخة HTML/CSS/JS عادية

موقع ثابت (Static) بالكامل. لا يحتاج بناء ولا Node ولا أي أدوات — كل ما تحتاجه هو رفع الملفات.

---

## 1) النشر على Vercel

### الطريقة الموصى بها: GitHub + Vercel (تحديث تلقائي)

1. أنشئ مستودعاً جديداً (Private) على **<https://github.com/new>** باسم `future-orders-site`
   — بدون تعليم على `Add a README` أو `.gitignore`
2. في صفحة المستودع اضغط **uploading an existing file**، واسحب **محتويات** هذا المجلد كلها
   (وليس ملف الـ zip) ثم اضغط **Commit changes**
3. في Vercel: **Add New → Project → Import Git Repository** واختر المستودع، ثم **Deploy**

بعدها أي تعديل تحفظه في GitHub يُنشر تلقائياً على الموقع خلال دقيقة.

### الطريقة السريعة: Vercel Drop (لمرة واحدة)

1. افتح **<https://vercel.com/drop>**
2. اسحب ملف الـ zip وأفلته، اختر اسم المشروع، ثم **Deploy**

> ⚠️ **مهم:** خاصية Drop **لا تُحدّث مشروعاً موجوداً** — كل سحبة تُنشئ مشروعاً جديداً برابط جديد،
> وستضطر لإعادة ربط النطاق في كل مرة. استخدمها للتجربة فقط، ولاعتماد الموقع استخدم GitHub.

### ربط النطاق الخاص بالشركة
من لوحة المشروع في Vercel: **Settings → Domains → Add**، ثم أدخل نطاقك (مثل `futureorders.sa`).

اختر طريقة **A Record / CNAME** — **ولا تستخدم خيار Nameservers** إذا كانت إيميلات الشركة
مستضافة على نفس النطاق، لأن ذلك ينقل إدارة DNS بالكامل إلى Vercel ويعطّل البريد.

> ⚠️ إذا كان سجل الـ MX يشير إلى اسم النطاق نفسه (مثل `futureorders.sa`)، فيجب أولاً
> تحويله إلى مضيف مستقل (مثل `mail.futureorders.sa` بسجل A يحمل عنوان خادم البريد الحالي)
> **قبل** تغيير سجل A الخاص بالنطاق إلى Vercel، وإلا تتوقف الإيميلات.

## 2) تفعيل نموذج التواصل (مهم — خطوة واحدة)

النموذج في صفحة **Contact.html** يستخدم خدمة **Web3Forms** المجانية.

1. افتح **<https://web3forms.com>** وأدخل بريد الشركة (مثلاً `info@futureorders.sa`).
2. سيصلك **Access Key** على بريدك فوراً.
3. افتح ملف `Contact.html` بأي محرر نصوص، وابحث عن السطر:

   ```js
   window.WEB3FORMS_ACCESS_KEY = 'YOUR_ACCESS_KEY_HERE';
   ```

4. استبدل `YOUR_ACCESS_KEY_HERE` بالمفتاح الذي وصلك، واحفظ الملف.

بعدها ستصل كل رسالة من النموذج مباشرة على بريدك.
(قبل وضع المفتاح، يعرض النموذج رسالة تنبيه بدل الإرسال.)

## 3) محتويات المشروع

```
index.html            الصفحة الرئيسية
Services.html         الخدمات
Projects.html         المشاريع
ProjectDetail.html    تفاصيل المشروع  (تقرأ ?id= من الرابط)
Contact.html          تواصل معنا + النموذج
vercel.json           إعدادات Vercel (تخزين مؤقت + ترويسات أمان)

assets/
  css/style.css       كل التنسيقات والأنيميشنز
  js/i18n.js          نصوص الموقع (عربي/إنجليزي) + بيانات المشاريع + محرّك اللغة
  js/main.js          سلوك الموقع (هيدر، عدّادات، شرائط متحركة، معرض الصور)
  logo.png            الشعار الملوّن
  logo-gold.png       الشعار الذهبي (يظهر فوق صورة الهيرو)
  riyadh-skyline.jpg  خلفية الهيرو
  logos/              ٤٣ شعار جهة حكومية وخاصة
  projects/           ٤٤ صورة مشاريع
```

## 4) كيف أعدّل المحتوى؟

| أريد أن... | افتح |
|---|---|
| أغيّر أي نص (عربي أو إنجليزي) | `assets/js/i18n.js` |
| أغيّر رقم الهاتف / الإيميل / العنوان | `assets/js/i18n.js` → `footer` و `contactPage.info` |
| أضيف مشروعاً جديداً | `assets/js/i18n.js` → `PROJECT_ORDER` + `PROJECT_IMAGES` + `PROJECT_TEXT` + `projectsPage.items` |
| أضيف شعار جهة جديدة | ضع الصورة في `assets/logos/` ثم أضف مسارها في `CLIENT_LOGOS` |
| أغيّر الألوان | `assets/css/style.css` → القسم `:root` في الأعلى |

**النصوص العربية والإنجليزية مرتبطة بالترتيب.** إذا أضفت عنصراً للعربية، أضف ما يقابله للإنجليزية في نفس الموضع.

## 5) صور فئات المنتجات (اختياري)

في صفحة `Services.html`، مربعات "فئات المنتجات" الأربعة ما زالت **placeholders** مخططة (لم تكن هناك صور لها في التصميم الأصلي).

لإضافة صور حقيقية:

1. ضع الصور في مجلد جديد `assets/categories/`
2. في `Services.html`، استبدل:
   ```html
   <div class="thumb"><span class="ph" data-i18n="servicesPage.imgPlaceholder">صورة منتج</span></div>
   ```
   بـ:
   ```html
   <div class="thumb"><img src="assets/categories/furniture.jpg" alt=""></div>
   ```

## 6) تشغيل الموقع محلياً على جهازك

افتح `index.html` بالمتصفح مباشرة — سيعمل كل شيء عدا صفحة تفاصيل المشروع في بعض المتصفحات.
للتشغيل الكامل، افتح موجّه الأوامر داخل مجلد الموقع ونفّذ:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`
